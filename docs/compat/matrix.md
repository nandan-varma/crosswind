# Compatibility matrix

Generated by `scripts/compat.sh` from `results.json`. Do not edit by hand.

How the tests run: each app is installed from Flathub on an arm64 guest, launched through a headless stub, and its frames are read back by the host. The guest renders on the CPU (pixman); there is no GPU path, so GPU-accelerated drawing (OpenGL, Vulkan, WebGL) is not exercised. Input is injected through the agent. `unknown` input means no new frame arrived within 2 seconds. Results are from the developer's Mac; a `works` rating does not cover every feature of an app.
